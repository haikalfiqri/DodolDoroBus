# Docs

| File | What it is |
|---|---|
| `progress_v4.md` | **The current plan** (single source of truth): feedback, lore, pets, priorities, timeline |
| `design/game_rules.md` | Rules and formulas: battle, pets, eggs, drop roll, cells, unlocks (backend + frontend) |
| `design/screens.md` | Screen list, flow, question panels, colours (frontend) |
| `design/data_model.md` | Tables v4 and API draft (backend) |
| `egg_pet_system_v4.md` | Egg and pet design: 5 eggs, 15 pets, growth, My Room |
| `player_journey.md` | Walkthrough from Day 1 to end-game, egg drop rates, pacing |
| `story/chapter1_script.md` | Chapter 1 scenes and art list (lines are in `content/dialogue/ch1.json`) |
| `story/chapters2-5_outline.md` | Chapters 2–5 roadmap and the template for adding a chapter |
| `prototype/codex_trial_prototype.html` | Clickable prototype (open in a browser; still shows the old spirit) |
| `archive/` | Old versions (v3 and earlier), history only |

Game numbers and text are in [`../content/`](../content/). If a doc and `content/` disagree, `content/` wins.

Large files such as slides (`.pptx`) and PDFs stay in the shared drive, not in this repo.
